# md2pdf — Markdown 转 PDF 工具

纯前端的 Markdown 编辑器 + A4 分页预览工具：左侧编辑、右侧**实时按 A4 自动分页**预览，一键导出与预览完全一致的 PDF。

无需安装、无需构建，浏览器打开即用。

## ✨ 功能特性

- **对半布局**：左侧 Markdown 编辑器（可拖拽分隔条调整宽度），右侧 A4 分页预览
- **自动分页**：段落、表格放不下时**整体移到下一页**，不会被拦腰截断；超长块（超长表格/代码）自动切片续页，不丢内容
- **即时预览**：输入后自动重排（150ms 防抖），字号/页边距等样式改动立即生效
- **样式可调**：正文字号、页边距、表格字号、表格间距
- **数学公式**：集成 KaTeX，支持行内 `$...$` 与独立 `$$...$$`，提供一键插入按钮
- **表格插入**：Word 风格「拖选行列」面板（8×10 网格），也支持自定义行列数
- **编辑器增强**：行号、自动换行、列表自动延续、Tab 缩进、常用 Markdown 语法按钮
- **上传与拖放**：支持 `.md / .markdown / .txt` 文件，点击「上传 MD」选择，或直接拖入左侧编辑区；自动载入内容并把文件名同步到导出文件名
- **保存与导出**：保存 `.md` 源文件；可导出「图片版」或「文字版」A4 PDF（可选页码）
- **深色主题**：一键切换，选择自动记忆
- **文件名自定义**：顶部输入框统一控制导出 PDF 与 MD 的文件名

## 🚀 快速开始

方式一：直接用浏览器打开 `index.html`（需联网加载 CDN 依赖）。

方式二（推荐）：启动本地静态服务

```bash
python3 -m http.server 8123
# 打开 http://localhost:8123/index.html
```

## 📖 使用说明

1. 在左侧输入或粘贴 Markdown 内容；或点击左下角「上传 MD」选择文件，也可直接把 `.md` 文件拖入左侧编辑区（拖入时会显示提示层，文件名会自动填入顶部输入框）
2. 通过顶部滑块调节正文字号、页边距、表格样式
3. 在顶部「文件名」输入框填写导出文件名（导出 PDF 与保存 MD 共用；上传 `.md` 时会自动填入其文件名）
4. 点击右上角「文字版 PDF」导出可搜索的矢量 PDF，或点击左下角「保存 MD」保存源文件

### 两种 PDF 的导出方式

| 版本 | 触发方式 | 特点 |
| :--- | :--- | :--- |
| **图片版** | 在顶部「文件名」输入框里按 `Enter`；或光标点进左侧编辑器后按 `Ctrl/Cmd + Shift + S`（按钮默认隐藏） | 逐页截图，与预览完全一致；纯位图，文字不可选中 |
| **文字版** | 点右上角「文字版 PDF」→ 打印窗口目标选「另存为 PDF」 | 矢量文字层，中文可选中/复制/搜索，链接可直接点击，图片更清晰 |

- 图片版快捷键绑定在编辑器的键盘事件上，焦点在右侧预览区时无效；**文件名框按回车不受此限制，是最省事的方式**。
- 文字版依赖浏览器自带的打印对话框，**必须在独立的浏览器标签页中打开页面**；IDE 内置预览 / 嵌入式 webview 不提供打印 UI，点击不会有反应，此时请改用图片版。
- 文字版打印建议勾选「背景图形」，代码块与表头底色才完整。
- 两种导出都取顶部输入框里的文件名，「导出页码」对两者都有效（页码在导出时添加，预览中不显示）。

### 编辑快捷键

| 快捷键                    | 功能               |
|:---------------------- |:---------------- |
| `Ctrl/Cmd + B`         | 加粗               |
| `Ctrl/Cmd + I`         | 斜体               |
| `Ctrl/Cmd + K`         | 插入链接             |
| `Ctrl/Cmd + S`         | 保存 `.md` 文件      |
| `Ctrl/Cmd + Shift + S` | 导出图片版 PDF（需光标在编辑器内） |
| 文件名框内 `Enter`       | 导出图片版 PDF      |
| `Tab`                  | 缩进（选中多行可批量缩进）    |
| `Enter`                | 自动延续列表（有序编号自动递增） |

## 🔧 自动分页原理

1. 在离屏容器中按「页面内容区同宽」渲染 Markdown（含 KaTeX 公式）
2. 测量每个顶层内容块（标题/段落/表格/列表）的偏移与高度
3. 以 A4 内容区高度（297mm − 上下页边距）为上限做贪心装箱
4. 放不下的块整体推到下一页；单个超过一页的块按页高切片续页
5. 逐页 `html2canvas` 截图，按序写入同一个 jsPDF 文档

这样做的好处是：**分页边界永远不会落在文字行或表格行中间**，且导出结果与预览 100% 一致。

## 🛠 技术栈

| 库                                               | 用途          |
|:----------------------------------------------- |:----------- |
| [marked](https://github.com/markedjs/marked)    | Markdown 解析 |
| [KaTeX](https://katex.org/)                     | 数学公式渲染      |
| [html2canvas](https://html2canvas.hertzen.com/) | 页面截图        |
| [jsPDF](https://github.com/parallax/jsPDF)      | PDF 生成      |

全部通过 CDN 引入，无构建步骤。

## ⚠️ 说明

- 图片版是**图像型 PDF**（每页一张位图），文字不可选中，换来与预览完全一致的分页；需要文字层请用「文字版 PDF」
- 文字版通过浏览器打印生成，依赖系统打印对话框，IDE 内置预览 / 嵌入式 webview 中无法使用
- 首次打开需要联网加载 CDN 资源
- 建议在 Chrome / Edge / Safari 等现代浏览器的**独立标签页**中使用
